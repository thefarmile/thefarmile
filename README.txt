# TheFarMile website

A responsive, single-page travel website for TheFarMile YouTube channel.

## Preview
Open `index.html` in any modern browser.

## Before publishing
1. Replace the placeholder YouTube URL `https://www.youtube.com/@TheFarMile` with your exact channel URL if different.
2. Replace the three sample video cards with real video titles, thumbnails and video links.
3. The email form is currently a front-end demo. Connect it to a mailing-list provider if you want to collect subscribers.
4. The photos are loaded from Unsplash and require an internet connection.

## Publish
Upload `index.html` to your web host's public website folder (for example, `public_html` on many shared hosting plans). If you use GitHub Pages, upload the file to the repository root and enable Pages in repository settings.
